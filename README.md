# 📊 CodeAlpha Task 3 — Data Visualization

## 📌 Project Overview

This project focuses on visualizing sales data using Python.
Different charts and plots were created to understand revenue,
profit, sales trends, categories, cities, and payment methods.

## 🎯 Objectives

- Analyze sales data visually
- Compare revenue across categories
- Analyze monthly revenue trends
- Compare profit across categories
- Analyze city-wise revenue
- Understand revenue and profit distributions
- Identify relationships between numerical variables
- Present data in an easy-to-understand format

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📈 Visualizations Created

1. Revenue by Category — Bar Chart
2. Monthly Revenue Trend — Line Chart
3. Profit by Category — Bar Chart
4. Revenue Share by Category — Pie Chart
5. Revenue by City — Bar Chart
6. Revenue Distribution — Histogram
7. Profit vs Revenue — Scatter Plot
8. Correlation Heatmap
9. Profit Distribution — Histogram
10. Quantity Sold by Category — Bar Chart
11. Orders by Payment Method — Bar Chart

## 💡 Key Insights

The visualizations provide an overview of sales performance,
revenue, profit, category performance, city-wise sales,
monthly trends, and payment-method distribution.

The charts make it easier to identify patterns and relationships
within the sales dataset.

## ✅ Conclusion

The project demonstrates how Python visualization libraries
can be used to transform sales data into meaningful visual insights.

This project improved practical understanding of Pandas,
Matplotlib, Seaborn, data analysis, and data visualization.
